# Autonomous-GNC-Satellite-Engine

An autonomous Python engine that implements reinforcement learning to adjust multivariable controls and systems between navigational adaptation, safety buffers, and energy efficiency. 

## Features & Characteristics
* Multi-Objective Reinforcement Learning: Utilizes a reward-based algorithm to preserve the satellite's overall state by rewarding progression in avoiding hazardous and harmful conditions.
* Proximity Evaluation & Safety Buffers: implements a pre-inflated radius for satellite, calculates distance between vehicle and obstacles to determine proximity, provides safety thresholds to alert for incoming adversaries, penalties for failure of obstacle avoidance.
* Actuator & Hardware Precaution: Ensures energy efficiency with propulsion hardware stability by penalizing constant multi-mode switching between chemical and ion thrusters which causes potential mechanical fatigue in valves.
* GNC Telemetry & Vectoring: Implements 3D thrust in units of acceleration and telemetry for position, velocity, and fuel.

## Quick Start

Run **Rocket Nozzle CEA Solver** using terminal/command prompt

### 1. Download ZIP Folder
Download, extract ZIP, and go to the folder of the project in files.

### 2. Activating a Virtual Environment
* Windows (Command Prompt):
  * python -m venv venv
  * venv\Scripts\activate
* Linux (Command Prompt):
  * python3 -m venv venv
  * source venv/bin/activate

### 3. Installing Dependencies/Packages
pip install -r requirements.txt

### 4. Execute Main & Display Image of Trade Study
* python main.py
* start outputs\lox_ch4_sea_level.png
